# prog-for-cyber-cw1

Security Event Logger

Description:
This program simulates a security event logging system. It records user login attempts and generates an event log for each attempt.

Features:
Records successful and failed login attempts
Generates a unique Event ID
Stores the username entered
Records the event type
Displays the date and time of each event
Indicates whether the login attempt was successful or unsuccessful

How to Run:
python3 security_event_logger.py

Purpose:
The purpose of this program is to demonstrate how security events can be monitored and logged for auditing and security analysis. The program tracks login attempts and provides a record of security-related events.
