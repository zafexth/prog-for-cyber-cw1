# prog-for-cyber-cw1

Cyber Security Utilities

Description:
This program provides a collection of cyber security utility tools that assist users with common security-related tasks. The application uses a menu-driven interface that allows users to access different security functions.

Features:
Password Strength Checker
Caesar Cipher Encryption Tool
Common Port Viewer
Menu-driven interface
Input validation and user interaction

How to Run:
python3 cyber_utilities.py

Purpose:
The purpose of this program is to demonstrate a range of cyber security concepts, including password security, encryption techniques and network services. The utilities provide practical examples of tools commonly used in cyber security environments.
