# prog-for-cyber-cw1

IP Address Validator

Description:
This program validates IPv4 addresses entered by the user and determines the IP address class.

Features:
Validates IPv4 address format
Checks that each octet is within the valid range (0-255)
Identifies IP address classes (A, B, C, D and E)
Handles invalid input

How to Run:
python3 ip_address_validator.py
