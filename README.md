# prog-for-cyber-cw1

Security Incident Manager

Description:
This program provides a simple system for managing security incidents. Users can add, view, search and delete incidents through a menu-driven interface.

Features:
Add new incidents
View all incidents
Search for incidents by ID
Delete existing incidents
Menu-driven interface

How to Run:
python3 security_incident_manager.py

Purpose:
The purpose of this program is to demonstrate the use of data structures and incident management processes commonly used in cyber security. The program allows security incidents to be recorded, monitored and managed in an organised manner.
